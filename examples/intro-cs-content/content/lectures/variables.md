# 变量与赋值

变量是一个有名字的存储位置。赋值语句 `x = 3` 的意思是：计算右边的值，再把结果存进名为 `x` 的位置。

## 先算右边，再存左边

```python
x = 3
x = x + 2
```

第二行先读取 `x` 当前的值 `3`，算出 `5`，再把 `5` 存回 `x`。所以这里的 `=` 不是数学里的“相等”，而是“存入”。

## 类型

值有类型，例如整数、小数、字符串。类型决定了值能参与哪些运算：两个整数可以相加，整数和字符串直接相加在很多语言中会报错。

| 值 | 类型 |
|---|---|
| `3` | 整数 |
| `3.5` | 小数 |
| `"3"` | 字符串 |
