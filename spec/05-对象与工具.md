# 05 对象与工具

## 5.1 对象类型声明

对象是插件产出的、带类型与版本的 JSON 数据，由工具产出、由渲染器展示。插件在清单中声明自己的对象类型：

```json
"objectTypes": [
  { "id": "flashcard_deck", "title": "闪卡组", "schemaVersion": "1.0.0", "schema": "schemas/flashcard_deck.json" }
]
```

| 字段 | 说明 |
|---|---|
| `id` | 贡献 ID；全局限定名为 `<插件 ID>/<id>` |
| `title` | 本地化文本 |
| `schemaVersion` | 该对象结构的 SemVer 版本；结构发生不兼容变化时**必须**提升主版本 |
| `schema` | 包内 JSON Schema 文件路径，描述对象信封中的 `value` |

对象 Schema **必须**使用 JSON Schema 2020-12，根节点为 `"type": "object"` 且 `"additionalProperties": false`，**不得**使用指向包外的 `$ref`。

## 5.2 对象信封

```json
{
  "objectType": "example.flashcards/flashcard_deck",
  "schemaVersion": "1.0.0",
  "objectId": "01J9Z6QK3V8N4T2W5X7Y9A0BCD",
  "createdAt": "2026-10-09T08:00:00Z",
  "producer": { "pluginId": "example.flashcards", "pluginVersion": "1.0.0" },
  "supersedes": null,
  "fallbackText": "闪卡组：变量与类型，共 3 张",
  "value": { "title": "变量与类型", "cards": [] }
}
```

定义见 [`schemas/object-envelope.schema.json`](../schemas/object-envelope.schema.json)。

- 插件产出对象时只提供 `objectType`（本插件的贡献 ID）、`value` 与 `fallbackText`。`objectId`、`createdAt`、`producer`、`schemaVersion` 由宿主填写，插件**不得**伪造。
- 宿主**必须**用声明的 Schema 校验 `value`，校验失败时丢弃该对象并向调用方报告错误。
- `fallbackText` 是纯文本，不超过 2000 个字符，用于无法渲染的场合与无障碍访问。
- `value` 序列化后**不得**超过 128 KiB。
- 对象不可变。需要修改时产出新对象，并由宿主在 `supersedes` 中记录被替代对象的 `objectId`。
- 对象不是学习证据。宿主**不得**依据对象内容判定学习者的掌握程度，见第 06 章。

## 5.3 工具声明

工具是可以被模型调用的能力。

```json
"tools": [
  {
    "id": "lookup_term",
    "title": "查询术语",
    "description": "按关键词查询计算机术语，返回定义、一个最小例子和常见误区。",
    "whenToUse": "学习者询问某个计算机术语的含义，或对话中出现需要澄清的术语时。",
    "whenNotToUse": "需要完整讲解一个主题、或需要最新资讯时。",
    "inputSchema": {
      "type": "object",
      "properties": { "term": { "type": "string", "minLength": 1, "maxLength": 64 } },
      "required": ["term"],
      "additionalProperties": false
    },
    "outputObjectTypes": ["glossary_entry"],
    "effect": "creates_object",
    "timeoutMs": 10000
  }
]
```

| 字段 | 说明 |
|---|---|
| `id`、`title` | 贡献 ID 与本地化展示名 |
| `description` | 给模型看的说明，不超过 1024 个字符 |
| `whenToUse`、`whenNotToUse` | 必需，分别说明适用与不适用的场景，帮助模型正确选择 |
| `inputSchema` | 输入参数的 JSON Schema，限制见下文 |
| `outputObjectTypes` | 可能产出的对象类型，必须已在本插件 `objectTypes` 中声明 |
| `effect` | `read_only`（不产出对象、不写存储）或 `creates_object`（可以产出对象、写私有存储） |
| `timeoutMs` | 100 到 120000 之间，默认 30000 |

`inputSchema` 只能使用以下子集：根节点 `"type": "object"` 且 `"additionalProperties": false`；关键字限于 `type`、`properties`、`required`、`additionalProperties`、`items`、`enum`、`description`、`minimum`、`maximum`、`minLength`、`maxLength`、`minItems`、`maxItems`；`type` 取值限于 `string`、`number`、`integer`、`boolean`、`array`、`object`。

0.1 的工具**不得**产生插件私有存储与对象之外的副作用，例如发送消息、修改外部系统中的数据、创建外部账号。通过 `host/http.fetch` 发出的 `POST` 请求只能用于查询。

工具最终以何种方式暴露给模型（直接声明，或经搜索按需加载）由宿主决定。

## 5.4 运行协议

声明了工具的插件以独立进程运行（见 1.5）。宿主与插件进程通过标准输入输出交换 JSON-RPC 2.0 消息：

- 每条消息是一行 UTF-8 JSON，以 `\n` 结尾，单行**不得**超过 4 MiB。
- 标准输出只能写协议消息。日志写到标准错误；宿主**可以**截断或丢弃日志，插件**不应**在日志中写入学习者内容。
- 进程工作目录为只读的包目录。宿主只提供必要的环境变量，**不得**传入宿主凭据；临时目录通过环境变量 `MENTORBIT_TMPDIR` 提供。

消息定义见 [`schemas/tool-messages.schema.json`](../schemas/tool-messages.schema.json)。

### 生命周期

```text
宿主 ── initialize ──▶ 插件 ── 结果 ──▶ 宿主
宿主 ── tools/call ──▶ 插件（可并发多次，期间插件可回调 host/* 方法）
宿主 ── $/cancel ────▶ 插件（可选）
宿主 ── shutdown ────▶ 插件 ── 结果 ──▶ 宿主
宿主 ── exit ────────▶ 插件（通知，插件随即退出）
```

**`initialize`**（宿主 → 插件，请求）

参数：`protocol`（`"mentorbit.tool/0.1"`）、`plugin`（`{"id", "version"}`）、`grants`（已授权的权限 ID 列表）、`locale`、`limits`（`{"maxConcurrentCalls": 整数}`）。

结果：`protocol` 与 `tools`（插件实际实现的工具 ID 列表）。`tools` 与清单声明不一致时，宿主**必须**拒绝启用该插件。

**`tools/call`**（宿主 → 插件，请求）

| 参数 | 说明 |
|---|---|
| `callId` | 本次调用的唯一 ID |
| `toolId` | 本插件内的工具 ID |
| `input` | 已由宿主按 `inputSchema` 校验的参数 |
| `scope` | `{"learnerRef", "sessionRef", "locale"}`，见下文 |
| `timeoutMs` | 本次调用剩余的时间预算 |

`learnerRef` 与 `sessionRef` 是不透明字符串。宿主**必须**为每个插件生成不同的 `learnerRef`，使不同插件无法据此关联同一学习者。

结果：

| 字段 | 说明 |
|---|---|
| `summary` | 给模型看的纯文本结果，不超过 4000 个字符 |
| `objects` | 可选，至多 16 个对象，每项为 `{"objectType", "value", "fallbackText"}` |
| `isError` | 可选，为 `true` 表示业务层面失败（例如查无此词），`summary` 说明原因 |

**`$/cancel`**（宿主 → 插件，通知）：`{"callId"}`。插件应当尽快停止该调用，并以 `cancelled` 错误响应。宿主在调用超时时发送取消，2 秒内仍未响应的，**可以**终止整个进程。

**`shutdown` / `exit`**：宿主发送 `shutdown` 请求，插件完成清理后返回 `{}`；宿主随后发送 `exit` 通知，插件**必须**退出。宿主在 `exit` 后 5 秒内**可以**强制终止进程。

### 宿主提供的方法

插件可以在处理 `tools/call` 期间向宿主发送以下请求。每个请求**必须**携带当前仍在进行的调用的 `callId`，宿主据此确定作用域；`callId` 无效或已结束时，宿主**必须**返回 `permission_denied`。因此插件无法在调用之外访问学习者相关能力。

| 方法 | 所需权限 | 参数 → 结果 |
|---|---|---|
| `host/storage.get` | `storage.plugin` | `{"callId", "key"}` → `{"value": JSON 或 null}` |
| `host/storage.set` | `storage.plugin` | `{"callId", "key", "value"}` → `{}` |
| `host/storage.delete` | `storage.plugin` | `{"callId", "key"}` → `{}` |
| `host/model.invoke` | `model.invoke` | `{"callId", "messages": [{"role", "content"}], "maxTokens"}` → `{"text"}` |
| `host/http.fetch` | `network:<源>` | `{"callId", "url", "method": "GET" 或 "POST", "headers", "body"}` → `{"status", "headers", "body"}` |
| `host/context.message` | `context.read:message` | `{"callId"}` → `{"text"}` |
| `host/objects.read` | `objects.read:<类型>` | `{"callId", "objectType"}` → `{"objects": [...]}` |
| `host/learner.read` | `learner.read:<维度>` | `{"callId", "dimension"}` → 投影，见第 06 章 |

存储键不超过 64 个字符，单个值不超过 64 KiB。`host/http.fetch` 的请求体不超过 256 KiB、响应体不超过 1 MiB。宿主**必须**只转发 `Accept`、`Accept-Language`、`Content-Type` 三个请求头，丢弃其余请求头，**不得**跟随重定向到未授权的源，**不得**附带 Cookie 或宿主自身的凭据。0.1 不支持插件携带自己的第三方 API 凭据，见附录 A。

## 5.5 错误码

| 代码 | 名称 | 含义 |
|---|---|---|
| -32700 | `parse_error` | 不是合法 JSON |
| -32600 | `invalid_request` | 不是合法的 JSON-RPC 请求 |
| -32601 | `method_not_found` | 方法不存在 |
| -32602 | `invalid_params` | 参数不符合定义 |
| -32603 | `internal_error` | 内部错误 |
| -32001 | `permission_denied` | 未获授权，或 `callId` 无效 |
| -32002 | `resource_exhausted` | 超出配额、频率或资源限制 |
| -32003 | `timeout` | 超出时间预算 |
| -32004 | `cancelled` | 调用已取消 |
| -32005 | `not_found` | 引用的对象、键或条目不存在 |
| -32006 | `upstream_error` | 网络或模型调用失败 |

错误对象的 `data.reason` 字段**必须**填写上表中的名称，便于不同语言的实现统一处理。
