# 04 渲染器

> 状态：草案

渲染器在界面中展示对象（见第 05 章），例如把一组卡片对象渲染成可翻面的闪卡。渲染器是运行在浏览器沙箱中的 HTML 页面，只能通过本章定义的消息协议与宿主交互。

## 4.1 声明

```json
"renderers": [
  {
    "id": "flashcards",
    "title": "闪卡",
    "objectTypes": ["flashcard_deck"],
    "entry": "renderer/index.html",
    "minHeight": 160,
    "maxHeight": 640
  }
]
```

| 字段 | 说明 |
|---|---|
| `id` | 贡献 ID |
| `title` | 本地化文本 |
| `objectTypes` | 能渲染的对象类型。本插件的类型写贡献 ID；其他插件的类型写 `<全局限定名>@<主版本>`，例如 `example.glossary/glossary_entry@1`，并且需要相应的 `objects.read` 权限（权限 ID 中不含 `@<主版本>`） |
| `entry` | 包内 HTML 入口文件 |
| `minHeight`、`maxHeight` | 可选，期望高度范围（CSS 像素），宿主**可以**进一步收紧 |

同一对象类型有多个可用渲染器时，宿主**必须**优先使用产出该对象的插件自带的渲染器；该插件没有渲染器时，由学习者选择，宿主**不得**未经学习者选择就改用其他插件的渲染器。

## 4.2 沙箱要求（宿主）

宿主**必须**在 `<iframe>` 中加载渲染器，并满足：

- `sandbox` 属性只包含 `allow-scripts`。**不得**包含 `allow-same-origin`、`allow-top-navigation`、`allow-popups`、`allow-forms` 或 `allow-modals`。
- 不授予任何 Permissions Policy 能力，例如摄像头、麦克风、定位、剪贴板读取。
- 为渲染器文档设置内容安全策略，至少等价于：

  ```text
  default-src 'none'; script-src <包资源源>; style-src <包资源源> 'unsafe-inline';
  img-src <包资源源> data: blob:; media-src <包资源源>; font-src <包资源源>;
  connect-src 'none'; form-action 'none'; base-uri 'none'
  ```

- 宿主页面**必须**通过自身的内容安全策略（`frame-src`）把渲染器 iframe 能加载的地址限制在包资源源以内。
- 渲染器**不得**让自身所在的 iframe 跳转到其他页面，例如修改 `location` 或使用 `<meta http-equiv="refresh">`。宿主**必须**监听渲染器 iframe 的加载事件：首次加载之后再次发生加载时，**必须**卸载该 iframe，并改为展示对象的 `fallbackText`。
- 宿主**应当**从与宿主主站不同的专用源提供渲染器资源，作为纵深防御。

渲染器在 0.1 中**没有**网络访问能力，即使插件申请了 `network:` 权限也不例外；所需数据全部通过对象传入。

## 4.3 消息格式

宿主与渲染器通过 `window.postMessage` 交换 JSON-RPC 2.0 形式的消息：

- 请求：`{"jsonrpc": "2.0", "id": <字符串或整数>, "method": "...", "params": {...}}`
- 响应：`{"jsonrpc": "2.0", "id": ..., "result": {...}}` 或 `{"jsonrpc": "2.0", "id": ..., "error": {"code": ..., "message": "...", "data": {...}}}`
- 通知：没有 `id` 的请求，不需要响应。

消息定义见 [`schemas/renderer-messages.schema.json`](../schemas/renderer-messages.schema.json)，错误码与第 05 章共用。

安全要求：

- 宿主**必须**只接受 `event.source` 等于该渲染器 iframe 的 `contentWindow` 的消息，其余一律丢弃。
- 渲染器**应当**只接受 `event.source` 等于 `window.parent` 的消息。
- 宿主**必须**校验每条消息的结构；单条消息超过 256 KiB 或每秒超过 50 条时，宿主**可以**终止该渲染器。

## 4.4 生命周期

```text
渲染器加载完毕 ── ui/ready（通知）──────────▶ 宿主
宿主 ─────────── render/init（请求）────────▶ 渲染器
渲染器 ───────── 响应 {} ──────────────────▶ 宿主
              …… 交互期间的消息 ……
宿主 ─────────── render/dispose（通知）─────▶ 渲染器
```

1. 渲染器**必须**在页面脚本就绪后发送 `ui/ready`，参数为 `{"protocol": "mentorbit.renderer/0.1"}`。
2. 宿主收到后发送 `render/init`，参数：

   | 字段 | 说明 |
   |---|---|
   | `protocol` | `"mentorbit.renderer/0.1"` |
   | `rendererId` | 全局限定的渲染器 ID |
   | `object` | 已通过 Schema 校验的对象信封（见 5.2） |
   | `locale` | 当前界面语言 |
   | `theme` | `{"colorScheme": "light" 或 "dark", "tokens": {...}}`，见 4.6 |
   | `grants` | 该插件当前已获授权的权限 ID 列表 |

3. 宿主开始加载 iframe 后 5 秒内未完成初始化（收到 `ui/ready` 并得到 `render/init` 的成功响应）时，**必须**改为展示对象的 `fallbackText`（见 5.2），并**可以**卸载该 iframe。
4. 宿主卸载渲染器前**应当**发送 `render/dispose`。渲染器**不得**依赖收到该通知。

## 4.5 方法

宿主发给渲染器：

| 方法 | 类型 | 说明 |
|---|---|---|
| `render/init` | 请求 | 参数见 4.4，返回 `{}` |
| `render/objectUpdated` | 通知 | `{"object": ...}`，对象有新版本 |
| `host/themeChanged` | 通知 | `{"theme": ...}` |
| `render/dispose` | 通知 | 即将卸载，无参数 |

渲染器发给宿主：

| 方法 | 类型 | 说明 |
|---|---|---|
| `ui/ready` | 通知 | 见 4.4 |
| `ui/resize` | 通知 | `{"height": 整数}`，宿主按声明与自身上限裁剪 |
| `ui/suggestPrompt` | 请求 | `{"text": "..."}`，不超过 500 个字符，返回 `{}`。宿主把它作为建议展示给学习者，**必须**由学习者确认后才发送，**不得**自动发送；返回只表示宿主已收到建议 |
| `ui/openLink` | 请求 | `{"url": "https://..."}`，返回 `{}`。宿主**必须**先征得用户确认；返回只表示请求已受理，不表示用户已同意打开 |
| `state/get` | 请求 | `{"key": "..."}`，返回 `{"value": JSON 或 null}` |
| `state/set` | 请求 | `{"key": "...", "value": JSON}`，返回 `{}`。保存视图状态（例如翻到第几张卡） |

每个方法的参数与结果在 [`schemas/renderer-messages.schema.json`](../schemas/renderer-messages.schema.json) 中按与 5.4 相同的规则命名：去掉 `host/` 或 `$/` 前缀，把 `/` 与 `.` 分隔的各段按驼峰拼接，再加 `Params` 或 `Result`。例如 `ui/suggestPrompt` 对应 `uiSuggestPromptParams` 与 `uiSuggestPromptResult`，`host/themeChanged` 对应 `themeChangedParams`。通知没有结果；没有参数的消息**可以**省略 `params`，等同于空对象。

`state/get` 与 `state/set` 需要 `storage.plugin` 权限，存储按“对象 × 学习者”隔离，键不超过 64 个字符，单个值不超过 16 KiB。

渲染器在 0.1 中**不得**提交学习证据。学习者在渲染器中的操作如需影响学习过程，**必须**通过 `ui/suggestPrompt`，由学习者确认后进入对话。

## 4.6 主题

`theme.tokens` 至少包含以下键，值为 CSS 颜色或字体值：`background`、`foreground`、`muted`、`accent`、`border`、`fontFamily`、`fontSizeBase`。渲染器**应当**使用这些值，以便在浅色与深色主题下都保持可读，并**应当**支持键盘操作。
