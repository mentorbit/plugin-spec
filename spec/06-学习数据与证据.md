# 06 学习数据与证据

> 状态：草案；6.3 证据提议为实验性

本章是 Mentorbit 区别于通用插件体系的核心：学习者状态只由内核维护，插件可以读取经过裁剪的投影、提议证据，但不能写入状态或下结论。

## 6.1 学习者状态维度

内核按维度维护学习者状态。0.1 的初始维度目录：

| 维度 | 记录什么 |
|---|---|
| `structure` | 学习位置、路径、前后关系与返回点 |
| `knowledge` | 概念理解、缺口、错误与误解的证据 |
| `human` | 明确表达的偏好、负荷、节奏与支持需求（敏感） |
| `value` | 目标、优先级、动机与兴趣 |
| `practice` | 尝试、辅助程度、产物、反馈与迁移情况 |

维度目录由内核登记，后续版本可以增加维度。插件**不得**以任何方式直接写入学习者状态。

## 6.2 读取投影

持有 `learner.read:<维度>` 权限的插件可以在工具调用期间通过 `host/learner.read` 读取该维度的投影：

```json
{
  "dimension": "knowledge",
  "asOf": "2026-10-09T08:00:00Z",
  "entries": [
    { "key": "intro_graph#variables", "summary": "能区分变量声明与赋值；对作用域仍有一次错误记录。", "confidence": "medium", "updatedAt": "2026-10-08T12:30:00Z" }
  ]
}
```

- 投影由宿主按当前会话与调用目的裁剪，至多 50 条，每条 `summary` 不超过 500 个字符。
- 投影**不得**包含学习者的身份信息、原始消息、作答原文或题目答案。
- 投影只在本次调用内有效。插件**不得**把投影内容写入私有存储、写入对象或通过网络发送。

## 6.3 证据提议（实验性）

> 0.1 中证据提议只对 `official` 插件开放，接口可能在 0.2 中变化。

持有 `evidence.propose:<事件类型>` 权限的插件可以通过 `host/evidence.propose` 提议一条证据事件：

| 参数 | 说明 |
|---|---|
| `callId` | 当前调用 |
| `eventType` | 内核已登记的事件类型，例如 `practice.attempt_submitted` |
| `payload` | 符合该事件类型契约的数据 |
| `idempotencyKey` | 插件生成的幂等键，同一键的重复提议**必须**被宿主判为重复，不得重复计入 |

结果为 `{"status": "accepted" | "rejected" | "duplicate", "eventId"?, "reason"?}`。

- 插件只能提议已登记的事件类型，**不得**定义新的事件类型或归约规则；新增事件类型属于内核变更，走第 07 章的变更流程。
- 宿主**必须**为每条证据记录来源：插件 ID、插件版本、信任等级、规则版本。证据是否被接受、如何改变学习者状态，由内核的确定性规则决定；插件**不得**指定状态变更的内容。
- 内核应当按来源的信任等级设置证据权重上限。
- 与作答相关的事件**必须**区分以下事实，不得合并或省略：

| 字段 | 取值 |
|---|---|
| `outcome` | `correct`、`incorrect`、`skipped`（跳过）、`no_answer`（未作答即离开）、`dont_know`（明确表示不会） |
| `assistance` | `none`、`hint`、`worked_example`、`answer_shown` |
| `attemptKind` | `first`（首次）、`retry_same`（原题重做）、`variant`（变式） |
| `questionRef` | 题目引用，见 3.2 |

## 6.4 禁止行为

所有插件，无论信任等级：

- **不得**把学习者描述为“已掌握”或“未掌握”并作为事实呈现；可以描述具体的作答表现。
- **不得**从作答表现推断学习者的情绪、人格、心理或健康状况，或给其贴上固定的学习风格标签。
- **不得**把有提示的成功等同于独立成功，把原题重做等同于变式迁移，或把任务完成等同于掌握。
- **不得**收集与其声明功能无关的学习者信息，**不得**要求学习者提供姓名、联系方式、证件号等身份信息。

## 6.5 保留与删除

- 宿主**必须**为学习者提供数据导出与删除功能，范围包括各插件的私有存储和插件产出的对象。
- 插件被卸载，或学习者要求删除数据时，宿主**必须**删除对应的私有存储；插件产出的对象随所在会话一并处理。
- 申请了任何 `network:` 权限的插件**必须**在清单中提供 `privacyPolicy`（HTTPS URL），说明会向外部发送哪些数据、用途和保留期限。
