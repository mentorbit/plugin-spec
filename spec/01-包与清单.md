# 01 包与清单

> 状态：草案

## 1.1 插件包结构

插件包是一个目录，分发时打包为 ZIP 归档。根目录**必须**包含清单文件 `mentorbit.plugin.json`。其余文件的布局由插件自定，清单通过相对路径引用它们。

示例：

```text
example.intro-cs/
  mentorbit.plugin.json      清单（必需）
  icon.png                  图标（可选）
  content/                  内容包数据
  renderer/                 渲染器入口与资源
  server/                   工具运行时入口
```

路径规则：

- 清单中的路径**必须**是相对于包根目录的相对路径，使用 `/` 分隔。
- 路径**不得**以 `/` 开头，**不得**包含 `..` 段、反斜杠、盘符或 NUL 字符。
- 宿主**必须**在解析后再次确认目标位于包目录内，并**不得**跟随指向包外的符号链接。

容量：宿主**必须**至少接受解压后不超过 20 MiB、文件数不超过 5000 的插件包，**可以**拒绝更大的包。

## 1.2 清单总览

清单是一个 JSON 对象，定义见 [`schemas/manifest.schema.json`](../schemas/manifest.schema.json)。

```json
{
  "specVersion": "0.1",
  "id": "example.glossary",
  "version": "1.0.0",
  "displayName": { "zh-CN": "术语速查", "en": "Glossary" },
  "description": "根据关键词查询计算机术语的定义与例子。",
  "defaultLocale": "zh-CN",
  "publisher": { "displayName": "Example Org", "url": "https://example.com" },
  "license": "Apache-2.0",
  "repository": "https://example.com/glossary",
  "icon": "icon.png",
  "requires": { "extensionPoints": ["tools"] },
  "permissions": [
    { "id": "storage.plugin", "reason": "缓存最近查询过的术语", "optional": true }
  ],
  "runtime": { "kind": "process", "interpreter": "python3", "entry": "server/main.py" },
  "contributes": {
    "objectTypes": [
      { "id": "glossary_entry", "title": "术语条目", "schemaVersion": "1.0.0", "schema": "schemas/glossary_entry.json" }
    ],
    "tools": [
      {
        "id": "lookup_term",
        "title": "查询术语",
        "description": "按关键词查询计算机术语的定义、例子与常见误区。",
        "whenToUse": "学习者询问某个计算机术语的含义时。",
        "whenNotToUse": "需要完整讲解一个主题时。",
        "inputSchema": {
          "type": "object",
          "properties": { "term": { "type": "string", "minLength": 1, "maxLength": 64 } },
          "required": ["term"],
          "additionalProperties": false
        },
        "outputObjectTypes": ["glossary_entry"],
        "effect": "creates_object"
      }
    ]
  }
}
```

各类贡献的字段见第 03 至 05 章；可运行的完整插件见 [`examples/glossary-tool`](../examples/glossary-tool/)。

## 1.3 字段

| 字段 | 必需 | 说明 |
|---|---|---|
| `specVersion` | 是 | 清单遵循的规范版本，格式 `主.次`，0.1 版固定为 `"0.1"` |
| `id` | 是 | 插件 ID，见下文 |
| `version` | 是 | 插件自身版本，必须是 SemVer 2.0.0 |
| `displayName` | 是 | 展示名，本地化文本，不超过 40 个字符 |
| `description` | 是 | 一句话说明，本地化文本，不超过 200 个字符 |
| `defaultLocale` | 是 | BCP 47 语言标签，本地化文本缺少某语言时回退到它 |
| `publisher` | 是 | 发布者展示信息：`displayName` 必需，`url`、`email` 可选 |
| `license` | 是 | SPDX 许可证表达式，闭源插件写 `"proprietary"` |
| `repository`、`homepage` | 否 | HTTPS URL |
| `privacyPolicy` | 条件 | HTTPS URL；申请了任何 `network:` 权限时必需，见 6.5 |
| `icon` | 否 | 包内 PNG 文件路径，建议 128×128 |
| `requires` | 否 | 插件运行所必需的条件，见 1.4 |
| `permissions` | 否 | 权限申请列表，见第 02 章；省略表示不申请任何权限 |
| `runtime` | 条件 | 声明了工具时必需，见 1.5 |
| `contributes` | 是 | 各扩展点的贡献，至少包含一项贡献 |

**插件 ID** 由发布者名与插件名组成，以 `.` 连接，整体匹配 `^[a-z][a-z0-9-]{1,38}\.[a-z][a-z0-9-]{1,38}$`。发布者名由插件目录（registry）在发布者注册时分配；宿主**不得**允许两个不同发布者使用同一发布者名。

**本地化文本** 是一个字符串，或一个以 BCP 47 语言标签为键、字符串为值的对象。使用对象时**必须**包含 `defaultLocale` 对应的键。

清单**不得**包含 Schema 未定义的顶层字段；扩展信息放在 `x-` 前缀的字段中，宿主**必须**忽略不认识的 `x-` 字段。

## 1.4 必需条件

`requires.extensionPoints` 列出插件正常工作所必需的扩展点，取值为 `contentPacks`、`renderers`、`tools`。宿主未实现其中任一扩展点时，**必须**拒绝加载该插件并说明原因。未列入的扩展点下的贡献，按 0.5 的规则忽略。

## 1.5 运行时

只有工具需要执行插件代码。内容包是纯数据；渲染器在浏览器沙箱中运行，不使用本字段。

```json
"runtime": { "kind": "process", "interpreter": "python3", "entry": "server/main.py" }
```

| 字段 | 说明 |
|---|---|
| `kind` | 0.1 只定义 `process`：宿主以独立进程运行插件，通过标准输入输出通信，协议见第 05 章。`wasm` 保留 |
| `interpreter` | 宿主提供的运行环境名称。0.1 定义 `python3`、`node`、`native` 三种 |
| `entry` | 包内入口文件路径；`native` 时为可执行文件 |

插件**不得**声明任意命令行。宿主根据 `interpreter` 与 `entry` 自行构造启动参数，**不得**经过 shell 解析。宿主不支持所声明的 `interpreter` 时，**必须**拒绝加载工具贡献。

说明：`native` 涉及多平台二进制与更大的审核难度，宿主可以只对 `official` 插件开放。

## 1.6 完整性

分发归档**必须**在根目录包含 `mentorbit.integrity.json`，由打包工具生成，列出包内除自身外每个文件的相对路径与 SHA-256。宿主安装时**必须**逐一校验，存在不一致、缺失或多余文件时**必须**拒绝安装。

```json
{
  "algorithm": "sha256",
  "files": {
    "mentorbit.plugin.json": "9f86d081884c7d659a2feaa0c55ad015a3bf4f1b2b0b822cd15d6c15b0f00a08"
  }
}
```

开发者以目录形式在本地加载插件时，宿主**可以**跳过完整性校验，但**必须**按第 02 章将其视为未审核插件。签名机制见第 08 章。
