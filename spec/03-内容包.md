# 03 内容包

> 状态：草案

内容包是只含数据、不含可执行代码的贡献，用于提供课程图、题库和讲义。内容包不需要 `runtime`，通常也不需要任何权限，是风险最低的插件类型。

## 3.1 声明

```json
"contentPacks": [
  { "id": "intro_graph", "kind": "course-graph", "path": "content/graph.json", "title": "计算机导论课程图" },
  { "id": "intro_questions", "kind": "question-bank", "path": "content/questions.json", "title": "导论练习题" },
  { "id": "intro_lectures", "kind": "lecture-set", "path": "content/lectures.json", "title": "导论讲义" }
]
```

| 字段 | 说明 |
|---|---|
| `id` | 贡献 ID |
| `kind` | `course-graph`、`question-bank` 或 `lecture-set` |
| `path` | 数据文件在包内的路径 |
| `title` | 本地化文本 |

每个数据文件**必须**通过对应的 Schema 校验，并且**必须**带有以下字段：

- `format`：数据格式标识，分别为 `mentorbit.course-graph/0.1`、`mentorbit.question-bank/0.1`、`mentorbit.lecture-set/0.1`，并且**必须**与声明的 `kind` 一致；
- `license`：内容的许可（SPDX 表达式或 `proprietary`）；
- `attribution`：内容来源与署名。

## 3.2 引用

内容条目通过引用相互关联：

- 同一插件内：`<内容包 ID>#<条目 ID>`，例如 `intro_graph#variables`。
- 跨插件：`<插件 ID>/<内容包 ID>#<条目 ID>`，例如 `example.intro-cs/intro_graph#variables`。

条目 ID 匹配 `^[a-z0-9][a-z0-9_-]{0,63}$`，在所属内容包内唯一。

宿主**必须**校验同一插件内的引用全部可解析。跨插件引用的目标未安装时，宿主**必须**把该引用当作缺失处理并保留原文，**不得**报错拒绝整个内容包。

## 3.3 课程图（`course-graph`）

定义见 [`schemas/content/course-graph.schema.json`](../schemas/content/course-graph.schema.json)。

- `nodes`：课程或知识点，含 `id`、`title`，可选 `summary`、`cluster`（所属主题群）、`tags`、`estimatedHours`、`source`。
- `edges`：有向关系，含 `from`、`to`、`relation`：

| `relation` | 含义 |
|---|---|
| `hard_prereq` | `from` 是 `to` 的必要前置 |
| `soft_prereq` | `from` 有助于学习 `to`，但不是必需 |
| `co_learn` | 两者适合一起学习，方向无意义 |

约束：

- `from` 和 `to` **必须**引用本图中存在的节点，**不得**相同。
- 同一对节点之间同一种关系**不得**重复出现。
- 由 `hard_prereq` 与 `soft_prereq` 组成的子图**必须**无环。
- 课程图表达的是关系，不是强制学习顺序。宿主**不得**仅凭图上的位置、距离或学习者自报的状态推断其掌握程度。

## 3.4 题库（`question-bank`）

定义见 [`schemas/content/question-bank.schema.json`](../schemas/content/question-bank.schema.json)。

每道题包含：

| 字段 | 说明 |
|---|---|
| `id` | 条目 ID |
| `type` | `single_choice`、`multiple_choice`、`true_false`、`short_answer`。`code`（编程题）保留，待判题扩展点开放 |
| `stem` | 题干，受限 Markdown（见 3.6） |
| `options` | 选择题必需，每项含 `id` 与 `text` |
| `answer` | 选择题为 `{"optionIds": [...]}`，判断题为 `{"value": true}`，简答题为 `{"reference": "...", "rubric": [...]}` |
| `explanation` | 解析，受限 Markdown |
| `hints` | 可选，按顺序给出的提示 |
| `nodes` | 关联的课程图节点引用 |
| `difficulty` | 1–5 的整数 |
| `variantOf` | 可选，指向同一题库中的另一道题，表示本题是它的变式 |

约束：

- 单选题的 `answer.optionIds` **必须**恰好一项；多选题**必须**至少一项；所列选项**必须**存在。
- `variantOf` **不得**指向自身，变式关系**不得**成环。
- **答案保密**：宿主**不得**在学习者提交作答或明确放弃之前，向其展示 `answer`、`explanation` 或未请求的 `hints`。宿主向模型提供答案用于判题时，**必须**确保该答案不会在提交前经模型输出泄露给学习者，例如只在独立的判题调用中使用。

说明：`hints` 与 `variantOf` 让宿主能够区分“有提示的成功”与“独立成功”、“原题重做”与“变式迁移”，见第 06 章。

## 3.5 讲义（`lecture-set`）

定义见 [`schemas/content/lecture-set.schema.json`](../schemas/content/lecture-set.schema.json)。

`lectures` 中每项含 `id`、`title`、`path`（包内 `.md` 文件）、`nodes`，可选 `estimatedMinutes`。讲义正文是 UTF-8 编码的受限 Markdown。

## 3.6 受限 Markdown

题干、解析、提示和讲义正文统一使用受限 Markdown：

- 基础语法为 CommonMark，另支持 GFM 的表格、删除线，以及 `$...$`、`$$...$$` 形式的 LaTeX 数学公式。**不**启用 GFM 的自动链接字面量：宿主**不得**把正文中的裸网址渲染为链接。
- 原始 HTML：内容**不得**包含原始 HTML（代码与代码块中作为文字出现的 HTML 不受此限）；宿主遇到时**必须**转义或移除，**不得**执行或渲染。
- 图片：**必须**引用包内的 PNG、JPEG、WebP 或 GIF 文件；**不得**引用远程图片或 SVG。行内写法与引用式写法同样适用。
- 链接：只允许 `https:` 链接，包括行内链接、引用式链接与 `<https://...>` 形式的自动链接；宿主**应当**在打开外部链接前提示用户。
